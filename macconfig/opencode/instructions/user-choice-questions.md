## User Choice Questions

- When requirements are ambiguous or multiple valid paths exist, ask a concise user question before committing to a direction.
- Prefer multiple-choice format with 2-5 options, plus an "Other" option for custom input.
- Include one "Explain tradeoffs first" option when the decision has meaningful pros/cons.
- Mark one option as "recommended" with a brief reason so the user can decide quickly.
- If the user does not answer, proceed with the recommended option and state the assumption.
- After the user answers, continue execution immediately without extra confirmation.
