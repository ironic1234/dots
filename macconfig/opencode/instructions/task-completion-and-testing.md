## Task Completion and Testing

- Treat each request as a complete engineering task; continue working until the full requested outcome is finished.
- Do not stop at a partial implementation when additional obvious steps are needed for completion.
- Prefer doing non-blocking follow-up work immediately instead of asking for confirmation.
- When requirements are ambiguous, make a reasonable default choice and continue, then clearly state assumptions.
- Validate work before finishing: run the most relevant tests, linters, or build checks for the affected code.
- If a test or check fails, investigate and fix the issue, then rerun verification until it passes or is blocked by external factors.
- Include a concise verification report with commands run and key outcomes.
- If verification cannot be run, explain exactly why and provide concrete commands the user can run locally.
