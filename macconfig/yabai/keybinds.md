# Yabai / Skhd Keybinds

## Layout
| Key | Action |
|---|---|
| `Alt+E` | Set space layout to BSP |
| `Alt+S` | Set space layout to stack |

## Focus
| Key | Action |
|---|---|
| `Alt+←/↓/↑/→` | Focus window in direction |
| `Alt+P` | Focus window east (alt) |
| `Alt+O` | Focus window west (alt) |

## Window Manipulation
| Key | Action |
|---|---|
| `Alt+Shift+←/↓/↑/→` | Swap window with neighbor |
| `Alt+F` | Toggle zoom-fullscreen |
| `Alt+X` | Close window |

## Display
| Key | Action |
|---|---|
| `Ctrl+Alt+←/→` | Move window to display 1/2 and follow |
| `Alt+L` | Focus display 1 |
| `Alt+J` | Focus display 2 |

## Workspaces
| Key | Action |
|---|---|
| `Alt+1-9,0` | Focus space 1-10 |
| `Alt+Shift+1-9,0` | Move window to space 1-10 |

## Apps
| Key | Action |
|---|---|
| `Alt+K` | Open Ghostty |
| `Alt+T` | Open Firefox Nightly |

## System
| Key | Action |
|---|---|
| `Alt+W` | Close window (Cmd+W) |
| `Alt+Q` | Quit app (Cmd+Q) |
