## Planning First Execution

- Start every non-trivial request with a concrete implementation plan before making edits.
- For multi-step work, create and maintain a todo list, then execute the plan in sequence.
- Keep planning lightweight for simple tasks and deep for complex tasks.
- Do not wait for confirmation unless blocked by ambiguity, missing credentials, or risky irreversible actions.
- Before implementation, identify the verification strategy (tests, lint, build, or checks) that proves completion.
- After implementation, run the planned checks and resolve failures before concluding.
